# TwinNet – Local Simulation of AWS VPC Peering

Name: Vaishnavi Subash Pillai
Register No: 2114242440228
Batch: 1 | Course: AWS | Submitted: 10 November 2026

A local Python simulation of private VPC peering between two VPCs
(10.10.0.0/16 and 10.20.0.0/16). It checks route tables and security-group
rules. No AWS resources were created.

## Run
python TwinNet_VPC_Peering_Simulator.py

- TwinNet_VPC_Peering_Simulator.py – the simulator (Python 3, no extra packages)
- docs/Vaishnavi_EWB_VPC_Peering.pdf – full project report
